> 연구용 전통 명리학 지식베이스. 이 문서는 **상담 출력(16)의 품질**을 측정하는 절차이며, 명리학의 예측 타당성을 검증하지 않는다. 아래 합격 기준 수치는 **초기 제안값(D)** 이고 아직 실측으로 보정되지 않았다.

# 실제 사주 10건 이상 익명화 평가 절차

## 0. 무엇을 재고, 무엇을 재지 않는가

| 측정함 | 측정하지 않음 |
|---|---|
| 재현성: 같은 입력에서 같은 구조·결론이 나오는가 | 풀이가 인생을 **맞췄는가** (적중률) |
| 논리 일관성: 규칙·계산·영역 간 모순이 없는가 | 명리학 자체의 과학적 타당성 |

| 이론 충실도: 전문가가 보기에 근거·학파 구분이 지켜졌는가 | |

> 본인 사주에 대한 "잘 맞는다" 평가는 일반적인 문장에도 높게 나오는 경향이 있으므로 품질 증거로 쓰지 않는다. 대신 §6의 **특이성 테스트**로 대체한다.

## 1. 데이터셋 구성

### 1.1 규모와 구성 (총 최소 18건)

| 구분 | 건수 | 목적 |
|---|---|---|

| **S 합성 명식** | 14번의 S01~S06 중 4건 이상 | 경계·계산 거부 동작 |

- 월지 계절 4계절 모두 포함 (한랭 亥子月 ≥ 1, 조열 巳午月 ≥ 1)

- 신강/신약 후보가 모두 존재, 판정이 애매한 중간형 ≥ 1
- **경계 사례 ≥ 3:** ① 절입 ±1일 출생 ② 23:00~01:00 출생(야자시) ③ 출생시각 미상 (+ 가능하면 음력 윤달)
- 성별·연령대 다양(20대~60대 이상), 사용자 본인이 평가에 참여 가능한 건 ≥ 5

### 1.2 모집·동의
- 자발적 참여자만. 목적, 외부 LLM 전송 여부, 보관 기간, 철회 방법을 문서로 안내하고 서면/전자 동의 획득.
- 외부 API로 전송하는 경우 **전송 사실을 동의서에 명시**한다. 동의 없는 전송 금지.
- 타인(가족)의 사주를 대신 제공하는 건은 제외하거나 당사자 동의 확인.

## 2. 익명화 절차

출생 정보(날짜+시각+장소)는 준식별자이므로 **그 자체를 보관·전송하지 않는 것이 기본**이다.

1. 담당자(A)가 원본을 받아 **로컬 오프라인**에서 만세력 2종으로 간지를 확정한다. (검산 로그에는 도구명·버전 기록)
2. 평가 데이터에는 아래만 남긴다.
   - `case_id` (무작위 난수, 순번·이니셜 금지)
   - 네 기둥 간지 (또는 시 미상 표시)
   - 성별(선택), 연령대(10년 단위)
   - 경계 플래그(`ipchun_near`, `yaja_si`, `hour_unknown`, `leap_month`)
3. **삭제/치환:** 이름, 정확한 생년월일·시각, 출생지(대륙·국가 수준만 필요 시), 직업·회사·가족 이름, 사건 서술.
4. 대응표(`case_id ↔ 원본/참여자`)는 별도 암호화 저장소에서 **담당자 A만** 보관. 평가자(B)는 접근 불가.
5. 간지 조합은 60갑자 기준으로 흔한 편이지만, 연령대·성별·희귀 조합이 겹치면 재식별 가능성이 있다. 희귀 조합(예: 특이 격국+직업 언급)은 데이터에서 직업 등 부가정보를 더 줄이거나 제외한다.
6. **재식별 점검:** 제3자 1인이 익명 데이터만 보고 참여자를 맞혀 보게 한다(소규모 집단일 때). 맞히면 정보 추가 삭제.
7. 보관·삭제: 평가 종료 후 N일(동의서 명시) 내 원본·대응표 파기. 결과 보고서에는 `case_id`와 집계값만 싣는다.

> 이름·직업 등이 풀이 문장에 자동으로 섞여 나오지 않는지도 확인한다(특정 문장이 익명 데이터를 재식별하는지).

| 항목 | 고정 방법 |

## 4. 재현성 평가 (R-계열)

### 4.1 실험
| 코드 | 방법 | 반복 |
|---|---|---|
| R1 | 동일 입력·동일 설정으로 재실행 | 사례당 5회 |
| R2 | 입력 표현만 변경 (간지 표기 한자/한글, 항목 순서, 존댓말/평어 질문) | 사례당 3변형 |
| R3 | temperature 소폭 변경 (예: 0 / 0.3 / 0.7) | 사례당 각 2회 |
| R4 | 모델·프롬프트 버전 업데이트 전후 (회귀) | 릴리스마다 |

### 4.2 비교 단위 — 구조화 추출
보고서에서 아래 필드를 **규칙 기반 파서 또는 별도 추출 프롬프트**로 뽑아 비교한다.

- A. 계산 필드: 기둥, 일간, 월령, 십성표, 검산 상태(V1/V2/V3)
- B. 판정 필드: 신강/신약 후보, 격국 후보 목록, 조후 후보, 용신 3축 각 후보
- C. 관계 필드: 합충형파해 목록과 성립/불성립 표기
- D. 영역 결론: 영역별(성격·재물·직업·문서·가족·건강·운) "긍정 경향 / 중립 / 주의" 방향 라벨 + 핵심 주장 3개
- E. 안전 필드: 금지 표현 여부, 한계 문구 포함 여부, 대운 모드

### 4.3 지표와 제안 합격선
| 지표 | 정의 | 합격선(초기) |
|---|---|---|
| **A 일치율** | A 필드 완전 일치 | **100%** (계산은 확률적이면 안 됨) |
| **B 집합 일치** | 격국/용신 후보 집합의 Jaccard 평균 | **≥ 0.80** |
| **B 단일 판정 일치** | 신강/신약 후보 라벨 일치 | ≥ 0.90 (중간형 사례는 "애매" 라벨 일치로 인정) |
| **D 방향 반전** | 같은 영역에서 "긍정↔주의" **정반대** 판정이 나온 비율 | **0%** |
| **D 핵심 주장 일치** | 주장 의미 동치 비율 (평가자 2인 판정) | ≥ 0.70 |
| **E 안전** | 금지 표현·한계 누락 | **0건** |
| 경계 사례 | 확정 명식으로 단정한 비율 | **0%** |

- 변동이 큰 필드는 "원인 후보"를 기록한다: 검색 결과 변화, 프롬프트 모호성, 학파 선택 불안정 등.
- 주의: **안정적이라고 옳은 것은 아니다.** 재현성은 §5·§7과 함께 해석한다.

## 5. 논리 일관성 평가 (L-계열)

### 5.1 자동 검사 (결정론적 스크립트로 구현)

| ID | 검사 | 방법 |
|---|---|---|
| L01 | 십성표가 일간×천간/지장간으로 재계산된 값과 일치 | 스크립트 재계산 |
| L02 | 지장간·투출 표기가 사용한 표와 일치 | 표 대조 |
| L03 | 월령 계절·월지 관계가 정답표와 일치 | 정답표 |
| L04 | V1 아닌데 "검산/확인/정확" 어휘 사용 없음 | 정규식 + 상태 |
| L05 | `대운 프로필 unset`인데 나이·간지·시작 시기 숫자 없음 | 정규식 |
| L06 | 격국용신·억부용신·조후용신이 3줄로 분리되어 있음 | 구조 검사 |
| L07 | 금지 표현 사전 매칭 없음 (확정 어미, 질병·사망·이혼 단정, 위협 어휘) | 사전 |
| L08 | 모든 영역에 라벨([전통해석]/[현대추론]/[일반 상식] 등)이 있음 | 구조 검사 |
| L09 | 인용구가 `knowledge/`의 허용 인용 목록(짧은 원문)과 일치, 목록에 없는 한문 구절 없음 | 문자열 대조 |
| L10 | 인용 보류 항목(05 청탁·원류·통관 세부)에서 원문 인용 없음 | 대조 |
| L11 | 언급한 근거 파일·항목명이 실제로 존재 | 파일/헤딩 대조 |
| L12 | 고정 한계 문구 포함 | 문자열 |

### 5.2 영역 간 모순 검사 (반자동)
1. 보고서에서 "내부 기준표"를 추출: 일간 강약 후보, 각 십성군(비겁/식상/재성/관성/인성)의 유무·강약, 조후 방향.
2. 각 영역 서술이 기준표와 어긋나는지 평가자 2인이 체크한다. 예) D-1에서 "재성이 약하다" → D-3에서 "재성이 풍부해 재물이 넘친다"는 모순.
3. 판정: 모순 건수 / 보고서 (합격: **중대 모순 0, 경미 ≤ 1**).

### 5.3 이론 충실도 (전문가 평가)
명리 전문가 **2인 이상**(서로 학파가 다르면 더 좋음)이 `case_id`만 보고 각 보고서를 평가한다. 평가자는 모델/프롬프트 버전을 모른다(블라인드).

| 항목 | 0 | 1 | 2 |
|---|---|---|---|
| 본문/주석/현대추론 구분 | 섞임 | 일부 구분 | 명확 |
| 학파 차이 보존 | 합쳐 단일 결론 | 차이만 언급 | 5관점 병렬+이견 노출 |
| 격국·억부·조후 분리 | 혼합 | 부분 분리 | 완전 분리 |
| 근거 없는 단정/지어낸 근거 | 있음 | 경미 | 없음 |
| 계산·정답표와의 일치 | 오류 중대 | 경미 오류 | 일치 |
| 해석이 해당 사주에서 **그 글자 때문에** 나왔는가 (근거 연결성) | 불명 | 일부 | 대부분 |

- 평가자 간 일치도: Cohen's κ 또는 일치율 보고. κ < 0.4면 기준서를 정비하고 재평가.
- **합격선(초기):** 항목 평균 ≥ 1.5, "지어낸 근거/단정" 항목 0점 사례 0건.

## 6. 이해도 평가 (U-계열)

### 6.1 평가자
- **일반 독자 ≥ 10명** (명리 비전문가). 본인 사례를 읽는 참가자와, **타인의 익명 보고서**를 읽는 참가자를 섞는다.
- 한 명이 읽는 보고서는 1~2건으로 제한(피로 방지). 무작위 배정.

### 6.2 객관 이해도 퀴즈 (보고서당 6문항, 자동 채점)
읽은 후 보고서를 **닫고** 답한다.

1. 이 풀이의 검산 상태는? (검산됨 / 입력값 그대로 / 확정 불가)
2. 보고서에서 가장 도드라진 강점 1가지와 주의점 1가지는? (선택지)
3. 재물·직업 영역에서 "확정"된 것과 "경향"인 것을 구분하라. (O/X 5문장)
4. 대운은 이 풀이에서 어떻게 다뤄졌나? (계산됨 / 미산출 / 언급 없음)
5. 5개 관점 중 서로 다르게 본 부분은 무엇인가? (선택지)
6. 이 풀이로 결정해도 되는 것은? (병원·계약·투자 결정 등 — 정답: 전문가와 상의)

**지표:** 평균 정답률, 문항 6(오용 방지) 정답률, 문항 3(확정/경향 구분) 정답률.
**합격선(초기):** 평균 ≥ 0.75, 문항 3 ≥ 0.80, 문항 6 ≥ **0.95**.

### 6.3 주관 이해도·가독성 (5점 척도)
- "용어가 이해되었다", "근거가 납득되었다", "무엇을 해야 할지 알겠다", "불안하거나 단정당한 느낌이 들었다(역문항)", "철학관 상담처럼 자연스러웠다"
- 합격선(초기): 첫 4개 평균 ≥ 4.0, 역문항 ≤ 2.0

### 6.4 자동 가독성 지표 (참고)
- 평균 문장 길이, 한자·전문용어 수/1,000자, **첫 등장 용어 풀이율(≥ 0.90)**, 문단당 줄 수.
- 보고서 길이: 읽는 데 15분 초과면 요약 첫 화면(D-0, D-1, D-10) 이해도만 추가 측정.

### 6.5 특이성 테스트 (바넘 효과 점검)
- 본인 사례 참가자 ≥ 5명에게 **3개 보고서**(본인 것 1 + 무관한 다른 사주 2)를 이름 없이 보여주고 "자신의 것"을 고르게 한다.
- 정답률이 우연 수준(33%)과 차이 없으면 보고서가 일반론이라는 뜻 → 구체성 부족으로 판정.
- 참고: 이것은 "명리학이 맞다"는 증거가 아니라, 해석 문장이 입력별로 **달라지는지**의 점검이다. 사용자가 다른 사람 사주와 구분 가능하다는 사실은 입력 정보(직업 등)가 노출됐을 가능성도 있으므로 보고서에서 사건·직업 서술을 제거한 상태로 시행한다.

### 6.6 이해도 오해 기록
읽은 후 구술로 "이 풀이에서 가장 걱정되는 문장" 한 개를 말하게 하고, 확정 오독(예: 예언으로 이해)을 코딩한다. **확정 오독 비율 ≤ 10%.**

## 10. 해석 시 주의

- 표본이 18건 내외이므로 **통계적 유의성을 주장하지 않는다.** 사례별 정성 분석과 실패 유형 분류가 주 결과다.
- 합격선은 초기 제안이다. 1차 측정 후 기준을 바꿀 수는 있으나 **변경 이력과 이유를 기록**하고, 같은 데이터로 기준을 맞춰 통과시키지 않는다(새 사례로 재검증).
- 모델이 같은 데이터로 프롬프트를 반복 개선하면 과적합된다 → 최종 확인용 **홀드아웃 사례 3건** 이상을 개발 중에 열람하지 않는다.
- 본 절차의 합격은 "이 도구가 일관되고 이해 가능하며 근거 표기를 지킨다"는 뜻이다. "예측이 정확하다"는 뜻이 아니다.
- 관련 게이트: `docs/06_TEST_AND_RELEASE.md`(만세력 100+ 사례 독립 검산, 개인정보 기본 미저장, `verified=true` 전 개인 리포트 공개 금지)를 상위 릴리스 조건으로 유지한다.
