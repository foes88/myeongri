> 연구용 전통 명리학 지식베이스. 여기서의 길흉은 해당 전통의 분류 언어이며, 미래 사건을 실증적으로 예측한다는 의미가 아니다. `원문`은 링크한 공개 전사본의 해당 장에서 대조한 짧은 부분만 인용한다. `합성`은 실제 고전 사례가 아니다.

# 계산 층: 만세력과 출생시각

**중요:** 계산은 전통적 해석보다 먼저 독립 수행한다. 여기의 선택지는 구현 정책이며 여섯 고전이 모두 동일한 알고리즘을 명시했다는 뜻이 아니다.

| 항목 | 계산 정책/검증 포인트 | 논쟁/불확실성 |
|---|---|---|
| 입력 | 양력/음력, 윤달, 출생지, 표준시, 출생시각, 시각 정확도 | 음력 윤달 정보 없으면 중지 |
| 년주 | 입춘 기준 세차를 기본 프로필로, 구정 기준 대안 병렬 | 절입 인근은 초 단위 검증 |
| 월주 | 12절(節)의 정확한 절입시각으로 월지 전환 | 음력 초하루로 월주 전환하지 않음 |
| 일주 | 시간대를 적용한 지역 달력일 및 60갑자 기준점 | 야자시(23시 전후) 일주 변경 학파 이견 |
| 시주 | 12시진(2시간)·일간에서 시간 유도 | 야자시, 진태양시 보정 이견 |
| 현지시간 | 역사적 UTC offset / DST / IANA 타임존 | 출생 당시 행정 시차 필요 |
| 진태양시 | 선택적 경도 및 균시차 보정 | 필수라는 합의 없음 |
| 대운 기산 | 출생에서 앞/뒤 절기까지 간격 계산 | 기준 절기, 환산비, 성별·음양 방향 차이 |
