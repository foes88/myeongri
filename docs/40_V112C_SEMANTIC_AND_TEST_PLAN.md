# v11.2c 의미 중복 정리 + 10초 이해도 평가 준비

> 외부 리서치 문서(“도식화와 요약형 리포트 병행 설계”)를 검토해 **검증 가능한 부분만** 반영했다. 그 문서는 소스·DOM·테스트를 직접 보지 못하고 캡처로만 분석했다고 스스로 밝혔고, 인용한 수치(탐색 37% 개선, 표본 크기 등)는 이 저장소에서 확인되지 않았다 → **수치는 적용하지 않았다.** 사람 평가 결과는 아직 없다(미평가).

## 1. 지적 사항을 직접 재어 본 결과
- “같은 의미가 최소 5곳(제목·보조문·연도 해설·주요 변화·종합운)에 반복”: 기본 화면의 요약 단위(핵심 해석·보조 문장·변화 카드·분야 요약) 사이 글자 2-그램 Dice 유사도를 합성 5개 연도 × (종합·재물)에서 쟀더니 **실제로 겹친 것은 2027년 하나**였다(보조문 ↔ 변화 카드 0.42, 변화 카드 ↔ 종합운/재물 0.32~0.51). 다른 해는 쌍 유사도가 모두 0.3 미만. (재물 탭의 0.38 은 ‘…크게 달라지지 않는 시기입니다’ 같은 분야 문장의 공통 틀 때문이며 의미 중복이 아니다.)
- 방법의 한계: 글자 2-그램 유사도는 의미 이해가 아니라 표면 겹침의 근사다. 임계값 0.4 는 위 측정에서 실제 반복(0.42 이상)과 무관한 쌍(0.3 미만)을 가르는 값으로 골랐다.

## 2. 이번에 바꾼 것 (표시만, 백엔드·원문 불변)
1. **의미 중복 건너뛰기:** 주요 변화 후보(달라지는 점·주제·적용 기간·점검/반대 근거) 중 핵심 해석·보조문 또는 이미 고른 카드와 유사도 ≥ 0.4 인 것은 카드로 만들지 않고, 다음 후보로 채워 최대 3개. 건너뛴 문장은 ‘자세한 해석 보기’ 안 원문에 그대로 있다(테스트). 2027년: 카드 1(‘수입 기반이 안정된 자리로…’)을 건너뛰고 ‘이 해의 주제’가 들어왔다.
2. **변화 카드 아이콘:** ↗ 달라지는 점 · ◎ 주제 · ◷ 기간 · ◇ 점검/반대 근거. 아이콘은 장식(`aria-hidden`)이고 의미는 글자 제목이 전달한다. 새 점수·그래프·판정은 만들지 않았다(실제 시계열 수치가 없는 판정에는 미니그래프를 넣지 않는다).
3. **접힘 머리글의 내용 예고:** ‘자세한 해석 보기 — 핵심 해석 전문 · 자세한 풀이 · 반대 근거와 한계’(700px 이상), ‘상세 해석 펼치기 — 설명 · 현실 관점 · 근거’. 네이티브 `<details>` 라 Enter/Space 로 열리고 펼침 상태가 보조기기에 전달된다.
- 이미 반영되어 있던 것: 핵심 1문장, 변화 ≤3, 분야 요약 1~2문장, 시기 ‘먼저 볼 시기’ ≤3, 근거·원문·월별·계산 상태 접힘, 첫 화면 질문 버튼.
- 하지 않은 것: ‘시기 3포인트’ 별도 타임라인(기존 연도 타임라인+‘먼저 볼 시기’가 같은 실제 데이터를 이미 보여 줌), 미니그래프, 컴포넌트 분리·Storybook(번들러 없는 정적 구조라 별도 작업), 실제 A/B(트래픽 없음).

## 3. 10초 이해도 평가 (사람이 수행 — 결과 없음)
**목적:** 새 구조가 “이 해의 핵심·주의점·중요 시기”를 10초 안에 전달하는지 사람이 확인.
**절차:** 합성 입력으로 만든 결과 화면(첫 화면만)을 평가자에게 10초 보여 주고 가린 뒤 세 질문에 답하게 한다. 명리 지식이 없는 사람 20~30명(소규모 방향 확인용). 평가자에게 엔진·버전을 알리지 않는다. 화면 버전(v11.2 / v11.2b / v11.2c)은 평가자마다 무작위로 배정하고 기록한다.
**질문과 정답 기준(화면의 원문에서 확인 가능한 것만):**
1. “이 해의 핵심은 무엇이라고 읽혔나요?” → 핵심 1문장(예: ‘기회를 살리기 좋은 흐름’)과 일치하면 정답.
2. “조심하거나 점검하라고 한 것은 무엇이었나요?” → ‘반대로 보는 근거’ 카드의 내용과 일치하면 정답. 화면에 없는 사건을 말하면 오답 + ‘오해’ 표시.
3. “중요한 시기는 언제였나요?” → ‘먼저 볼 시기’ 또는 ‘변화가 적용되는 기간’과 일치하면 정답.
**기록표(빈칸):** 평가자 ID | 화면 버전 | Q1 | Q2 | Q3 | ‘좋다/나쁘다’로 오해했는가 | 메모
**분석 기준:** 문항별 정답률, 오해율, 버전 간 비교. 표본이 작아 통계적 유의성을 주장하지 않는다. 다른 지표(질문·저장 전환 등)는 이용자가 생기면 별도로 설계한다.
**주의:** 가짜 응답을 채우지 않는다. 평가가 없으면 이해도는 “미평가”로 남는다.

## 4. 검증
- 신규 `tests/browser/test_v112c_semantic.py`(3): 5개 연도 모두에서 핵심 해석·보조문·변화 카드 쌍의 유사도 < 0.4, 건너뛴 문장이 페이지에 그대로 존재, 아이콘 `aria-hidden` + 글자 제목, 접힘 머리글 내용 예고.
- 기존 원문 보존·판정 라벨 = API 판정 테스트 통과(상세는 전체 실행 결과 참고).
