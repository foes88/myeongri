# v7.0 — 종합 통변 품질 검증 · LLM 연결 설계 · 운영 배포 게이트

> 상태: 로컬 검증 단계. **main 병합·push·운영 배포 없음. 실제 LLM/외부 API 호출 없음.** 평가는 모두 합성 명식(실제 출생 정보 아님).

## 1. 평가 방법 (자동 지표 ↔ 사람 평가 구분)
| 구분 | 내용 | 상태 |
|---|---|---|
| 자동 지표 | `python -m tools.eval_synthesis` (합성 명식 20개: 기준·격국억부충돌·근거희박·무작위 17). 명식 고유성, 재물/직업 차이, 2027/2030 차이, 대운 교체 언급, 반대 근거 노출, 문장 중복, 전문용어 누수, 한자 잔존, 미래 단정 표현, 근거 번호 유효성, 고전 상태 표기, 문장 길이 | 수행 |
| 사람 평가 | 이해도, 통변의 설득력, “내 사주 같다”는 느낌, 현실 연결의 적절성 | **미수행** — 평가자 필요. 자동 지표는 이를 대신하지 않는다 |

## 2. 자동 평가 결과 (20개 명식)
- 재물≠직업 요약 20/20, 2027≠2030 20/20, 반대 근거 노출 20/20, 근거 번호 유효 20/20, 고전 상태 표기 유효 20/20.
- 명식 고유성: 핵심 해석 첫 두 문장이 서로 다른 명식 18/20, 재물·직업 요약 조합 19/20, 명식 쌍 평균 문장 겹침 0.19.
- 중복 문장 비율 평균 7.6%(기존 12~14%), 전문용어 누수 0, 첫 화면 한자 잔존 0, 미래 단정 표현 0, 근거 번호 없는 풀이 0.
- 길이(10년): 기존 평균 6,944자 → 2,981자(5단 해석 포함).
- 한계: “대운 교체 언급 20/20”은 합성 대운 배열이 모두 2030-06-15 교체라 변별력이 없다. 근거 희박 명식은 원국 구조가 0이어도 2030년 대운·세운 변화가 있어 ‘근거 부족’ 플래그가 서지 않고, 대신 “원국만으로는 뚜렷한 구조가 없고 대운·세운이 들어올 때 나타나는 구조”라고 말한다.

## 3. 상담 문장 구조 (5단)
모든 분야별 핵심 해석(`synthesis.readings`)은 ① 의미 ② 판단 근거(엔진 증거를 위치·십성 뜻풀이로 옮김, 증거에 없는 글자 금지) ③ 현실 연결(‘살펴볼 상황의 예’, 분야×구조별 렌즈) ④ 반대 근거 ⑤ 해석 범위(결과 확정 금지 + 규칙의 고전 확인 상태)로 구성한다. 재물·직업·사업은 같은 구조도 다른 렌즈로 설명한다. 근거가 없는 구조는 생성하지 않는다. 화면에서는 분야별로 접어 두었다(모바일 스크롤 때문).

## 4. LLM 연결 실험 설계 (미실행)
```
결정론 엔진(계산·규칙·고전 상태) → answer() → synthesis(핵심 판단 선택) → EvidenceBundle(key_judgments, allowed_*, classical_status, limits, fallback_text)
   → Provider.generate(요청, 번들)  ← 이번 단계에서는 TemplateProvider/None 만 사용
   → validate(): 허용 사실 검사(용어·간지·연도·claim_id), 길이, 고전 근거 위장, 미래 단정 → 실패 시 fallback
```
- LLM 은 `key_judgments` 의 문장을 말투·연결만 바꿔 전달한다. 판단을 고르거나 새 주장을 만들지 않는다.
- 추가 필요 검증(연결 전): ① 문장 단위 claim 보존 검사(번들 문장 중 누락·순서 변경 허용 범위) ② 반대 근거 문장 삭제 금지 검사 ③ ‘확정하지 않습니다’ 계열 한계 문장 보존 검사 ④ 숫자·연도·간지 화이트리스트(이미 있음) ⑤ 지연·비용 상한과 타임아웃 ⑥ 출생 정보·원문이 프롬프트에 들어가지 않음(번들은 이미 비식별).
- **LLM 없이 가능한 품질**: 명식별 차이, 근거 추적, 반대 근거, 5단 구조, 짧은 요약. **LLM 이 필요한 부분**: 문장 다양성(같은 구조=같은 문장), 질문 맥락에 맞춘 연결·전환, 사람 통변 같은 서술 흐름, 사용자 질문에 직접 답하는 문장.
- 실험은 별도 승인 후 (a) 오프라인 고정 샘플 20개, (b) 검증 통과율·fallback 비율·사람 평가 비교로 시작한다.
