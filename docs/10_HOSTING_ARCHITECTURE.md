# FastAPI 안전 호스팅 아키텍처 (설계만 — 배포하지 않음)

> 이 문서는 설계다. 공개 URL 배포, DNS, 클라우드 계정 연결은 **별도 승인 전까지 하지 않는다.** 현재 Git 연동은 브랜치 push 시 정적 화면(`web/`) 미리보기를 자동 생성하므로, 배포를 보류하는 동안은 브랜치 push 자체도 승인 후 한다.

## 현재 제약 (코드 기준)
| 항목 | 현재 | 서버리스(Vercel Functions 등) 적합성 |
|---|---|---|
| 천문 데이터 | JPL DE421 16MB 를 최초 실행 때 내려받아 `backend/data/` 에 저장 | 콜드스타트마다 내려받으면 지연·실패. 이미지/볼륨에 포함 필요 |
| 상담 저장 | `data_private/consult/` 파일(write-once, 해시) | 서버리스는 파일 시스템이 휘발성 → **저장 불가** |
| 의존성 | skyfield, numpy, lunar-python, korean-lunar-calendar | 번들 크기 큼, 계산 1~수 초 |
| 비밀/개인정보 | 출생정보·토큰 | 로그·프록시 캐시 노출 방지 필요 |

→ **상시 컨테이너 + 관리형 DB/객체 저장소** 구성이 적합하다. 정적 화면은 현행 Vercel 정적 배포를 유지할 수 있다.

## 권장 구성
```
브라우저 ─HTTPS→ [정적 화면 CDN]            (web/, noindex)
        └HTTPS→ [API 게이트웨이/리버스 프록시: TLS, WAF, rate limit, 요청 본문 로그 금지]
                    └→ [FastAPI 컨테이너 ×N (무상태)]
                          ├→ PostgreSQL (consult/report/credit, 출생정보는 앱 레벨 암호화 컬럼)
                          ├→ 객체 저장소 (precommit write-once: 버전관리+객체 잠금, 해시 검증)
                          ├→ KMS (envelope key)  · 비밀 저장소 (환경변수 직접 주입 금지)
                          └→ (선택) LLM 어댑터 — 별도 egress 프록시, 출생 원문 미전달(구조 JSON 만)
```

## 필수 보안 통제
1. **인증·소유권**: 상담별 토큰(현재) → 계정 인증(OIDC)로 대체. 토큰은 해시만 저장, URL 에 넣지 않음, 헤더 전용.
2. **CORS**: `CORS_ORIGINS` 를 실제 화면 도메인 하나로 제한(현재 기본값은 로컬뿐). 와일드카드 금지.
3. **레이트 리밋/남용 방지**: IP+토큰별 분당 한도, 무료 체험 한도, 요청 크기 제한(질문 500자·연도 10개는 이미 제한).
4. **로그**: 구조 로그는 식별자·상태만(구현: `myeongri.consult` 로거, 테스트로 명식·출생·질문·토큰 미노출 확인). 접근 로그의 쿼리스트링/본문 기록 끔. 에러 트래커에도 본문 전송 금지(스크럽).
5. **암호화**: 전송 TLS1.2+, 저장 시 필드 암호화(birth_enc, consult text), 백업도 암호화·보존기간 명시.
6. **write-once 기록**: 사전 분석 기록은 DB 행이 아닌 객체(불변) + 해시 컬럼; 조회 시 재검증(구현됨). 변경은 revision 추가만.
7. **비밀**: LLM/PG 키는 서버 비밀 저장소에서 런타임 주입. 프런트·저장소에 두지 않음(`.env.example` 만).
8. **공급망**: 의존성 고정(lock), 취약점 스캔, 이미지 서명. sxtwl 등 검증 전용 도구는 런타임 이미지에 포함하지 않음.
9. **데이터 거버넌스**: `data_private/`(외부 원자료)는 이미지에 포함하지 않음. 라이선스 미확인 자료는 서비스 경로에서 읽지 않는다.
10. **가용성**: 천문 엔진은 순수 함수라 수평 확장 가능. DE421 은 이미지에 포함, 헬스체크 `/api/v1/health`(현재 `calendar_verified:false` 노출).

## 배포 전 선결 조건 (미충족 시 배포 금지)
- 위 보안 통제 구현·테스트, 개인정보 처리방침/약관 법률 검토(v6.3 G6·G10).
- 공개 Git 이력 정리 결정(docs/08), 외부 자료 이용 조건 확인.
- 승인된 대상 환경과 도메인, 접근 제한(사내/초대) 여부 결정.

## 단계안
1. 로컬 Docker Compose(API+Postgres+MinIO)로 재현 → 2. 비공개 스테이징(IP 제한/SSO) → 3. 소규모 초대 베타(무료·고지 강화, 유료 없음) → 4. (게이트 통과 후) 공개.
