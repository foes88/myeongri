# v11.2b 텍스트 밀도 축소

> 표시 계층만 바꿨다. 백엔드 판정·API 응답·원문 문장은 그대로이며, 요약은 기존 원문의 문장(또는 구간 수 같은 사실)일 뿐 새 판정·단정이 아니다. 이해도 개선은 **미평가**.

## 1. 변경
| 영역 | 기본 화면 | 접힘(원문 보존) |
|---|---|---|
| 핵심 해석 | 핵심 1문장 + 보조 1문장(두 줄 이내, `line-clamp`) + 버튼 2개 | ‘자세한 해석 보기’ 맨 위에 **핵심 해석 전문**(원문 그대로) + 해 패널 |
| 주요 변화 | 항목 최대 3개, 각각 제목 1개 + 요약 1문장(원문의 첫 문장, 또는 ‘이 해는 N개 구간으로 나뉩니다.’) | 나머지 원문·구간 목록은 ‘자세히 보기’. 핵심 해석과 같은 문장의 항목은 생략 |
| 분야별 해석 | 핵심 요약 1~2문장(종합운은 핵심 해석과 겹치지 않는 첫 문장) | ‘상세 해석 펼치기’ → **설명·현실 관점** → ‘근거 보기’(단계적) |
| 시기별 흐름 | ‘먼저 볼 시기’ 최대 3개(기존 ‘가장 달라지는 해’ 표시 사용), 타임라인·표 | 기호 범례·긴 안내, 월별 상세(원래 접힘) |
| 계산 상태·네 기둥 | 한 줄 요약(‘계산 상태: 참고할 수 있습니다 · 내 사주(네 기둥) 보기’) | 계산 상태 목록·네 기둥 표 |
| 질문·저장 | 첫 화면에 주 버튼 ‘궁금한 점 물어보기’(누르면 질문창으로 이동·입력 가능), 질문창 → 저장 → 계산 상태 순. 저장 안내는 ‘저장하려면 로그인이 필요합니다. 출생 정보 원문은 저장하지 않습니다.’ 한 줄 | |

## 3. 검증
- 신규 `tests/browser/test_v112b_density.py`(7): 핵심 해석 1문장+보조 ≤1문장이 **원문 머리 문장의 앞부분**이고 전문이 접힘에 있음, 주요 변화 ≤3개·제목+요약 1문장이며 요약이 API 원문의 문장이거나 구간 수 사실, 분야 패널 기본 요약 ≤2문장→설명→근거 순 공개, 범례·월별·계산 상태·근거 접힘 + 먼저 볼 시기 ≤3개, 첫 화면의 질문 버튼(44px 이상)과 이동·포커스, 기본 화면 글자 수 상한 1,400자.
- 기존 원문 보존 테스트(선택한 연도·분야의 모든 원문 문장이 화면에 존재)와 판정 라벨 = API 판정 테스트가 그대로 통과.

## 4. 한계
- 1440px 에서는 버튼 행·‘먼저 볼 시기’ 때문에 페이지 길이가 −6% 에 그쳤다.
- 종합운 기본 요약은 한 문장이다(핵심 해석과 겹치는 문장은 다시 쓰지 않는다).
- 사람이 읽고 평가하지 않았다.
