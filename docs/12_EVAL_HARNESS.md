# Eval-Harness Track A — 상담 품질 자동 평가

실행: `cd backend && python -m app.evaluation.run` → `backend/golden/eval_trackA_report.json`, `eval_human_template.csv`
테스트: `python -m pytest -q tests/test_evaluation.py`

## 무엇을 재는가 / 재지 못하는가
| 자동 평가가 측정 | 사람 평가가 필요 |
|---|---|
| 명식 고유성(내용 문장 중 명식·연도·claim에 묶인 비율) | 상담의 깊이, 설득력 |
| 근거 수·그래프 연결성·반대 근거 보유율 | 실제 도움 여부 |
| 고전 출처 상태, 고전 근거 과장 문장 수 | 일반인 이해도의 실제 값(자동은 문장 길이·전문용어 밀도·용어 설명률 대리 지표뿐) |
| 학파 충돌 설명 여부 | 후속 질문 대응의 질 |
| 연도별·분야별 해석 차이, 반복 일관성 | 과잉 단정의 맥락 판단 |
| 단정 표현 비율, 완곡 표현 비율 | |

**전문 상담 결과(철학관 등)와의 비교 자료가 없으므로 어떤 우월성도 주장하지 않는다.** 예측력(Track B)은 이 평가의 대상이 아니다.

## 데이터셋 (합성, 개인정보 없음)
- 한 가지 요인만 바꾼 12쌍(D01~D12): 일간만 / 월령만 / 통근 / 격국 후보 / 조후(계절) / 합충 / 대운만 / 세운(연도)만 / 분야만 / 연애 vs 가족 / 대운 교체 연도 / 성별.
- 각 쌍은 "어떤 해석 측면이 달라져야 하는가(expected_facets)"를 사전에 고정한다. 결과가 이를 포함하면 sensitive.
- 바넘 검사용 합성 명식 12개(시드 고정). 합성 명식은 달력상 실현 불가능한 조합일 수 있으며(`calendar_realizable` 불리언만 기록, 날짜 미저장) 실제 출생정보와 연결하지 않는다.
- 통제 실험: 같은 입력 두 번 → 거리 0이어야 한다. 표현만 바꾼 답변 → 문장 거리는 있지만 판단 서명 거리는 0(= cosmetic)이어야 한다.

## 바넘 효과 검사 (문자열 중복률만 쓰지 않음)
1. 문장을 마스킹(간지·연도·claim_id·따옴표 라벨·숫자 → 자리표시자)해 "틀"이 같은지 본다.
2. 틀이 같아도 언급된 사실이 명식마다 다르면 **사실을 담은 틀**(일반론 아님)로 분류.
3. 사실 자리표시자가 없고 여러 명식에서 같은 문장은 **일반론 후보**: 전개·단서 문구(분석 주장 아님) / 규칙 수준 문장(같은 구조를 가진 명식이면 동일) / 그 밖의 일반론으로 세분. "그 밖의 일반론"만 실제 바넘 위험으로 본다.
4. 판단 내용의 차이는 **의미 서명**(규칙·상태, 구조 라벨, 운 관계, 궁위 근거, 특징 항목)의 자카드 거리로 따로 잰다. 문장이 다르다는 것만으로 좋은 분석이라고 보지 않는다.

## 현재 결과 요약 (합성 데이터, 결정론적 템플릿 상담)
`eval_trackA_report.json` 참조. 12쌍 모두 기대 측면에서 변화(sensitive), 표현만 다른 쌍(cosmetic) 0, 통제 거리 0, 반복 일관성 동일. 바넘 검사에서 "그 밖의 일반론" 0건이나, 전개·단서 문구와 규칙 수준 문장이 상당 비율 반복된다(분석 주장이 아닌 문구이거나 구조 의존 문장). 이 수치는 **템플릿 기반 상담이 구조에 반응한다는 것**을 보일 뿐 상담이 도움이 된다는 증거가 아니다.

## 사람 평가 (미수행)
`eval_human_template.csv`: 평가자 유형(전문가/일반인 분리), 블라인드 라벨, 1~5점 9개 항목. 동의·비식별 전사·문체/길이 편향 통제·평가자 간 일치도 측정은 사람 평가 단계에서 수행해야 하며 아직 하지 않았다.
