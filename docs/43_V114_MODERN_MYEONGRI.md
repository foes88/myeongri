# v11.4 Modern Myeongri — 종합운 화면 전면 개선 (백자와 옥색)

> 명리 판정·계산·점수·톤은 바뀌지 않았다(300개 판정·헤드라인 항목 동일, 날짜 구간 위반 0). 바뀐 것은 색·간격·글자·정보 구조와, 기간 설명 문장의 사실관계다. **사람 평가는 없다 → 10초 이해도·사용성은 미평가.**

## 1. 디자인 시스템
- 색은 `:root` 토큰 한 곳에서 정의(`--bg-page #F7FAF9` `--bg-surface #FFFFFF` `--bg-subtle #F0F5F4` `--text-primary #192E32` `--text-secondary #5A6D70` `--brand-primary #187C79` `--brand-hover #126662` `--brand-soft #DFEFEB` `--border-default #DCE5E4` `--border-strong #B6C9C6`). 기존 변수(`--paper`, `--ink`, `--seal`…)는 새 토큰을 가리키게 다시 정의해 모든 화면이 함께 바뀐다. 하드코딩되어 있던 적갈색(`#8d3a21`, `#7d3320`, `rgba(166,70,42,…)`)·베이지 중립색도 치환(마우스 오버 색 불균형의 원인).
- 보조 글자색은 요청 팔레트의 `#637477` 을 `#5A6D70` 으로 약간 진하게 했다(연한 배경 위에서 4.5:1 확보).
- 대비(흰 바탕): 본문 ≈14:1, 보조 ≈5.4:1, 강조 글자 `#126662` ≈6.2:1, 흰 글자 on `#187C79` ≈5.0:1.
- 판정 색: 초록/빨강 → 옥색(기회)·호박색(주의)·회청(안정·양면 등). 의미는 기호와 글자가 함께 전달.
- 마우스 오버·선택·눌림은 한 규칙(옥색 테두리 + 연한 옥색 배경, 0.15초). 움직임 줄이기 설정에서는 전환 없음.
- 글꼴: 웹폰트 로딩 없음(시스템 고딕 스택, 로딩 비용 0). 제목도 같은 계열로 통일.

## 3. 정보 구조
- **A 핵심 결론:** 연도 선택·판정 칩·헤드라인(28~34px)·쉬운 요약. ‘좋은 흐름/조심할 점’은 응답의 구조화된 `signals` 에서만 만들어 데스크톱 2열·모바일 1열 블록으로 표시(항목이 없으면 만들지 않음).
- **B 올해 주요 변화:** 최대 3개. 구간이 나뉘는 해에는 엔진 구간 경계의 **날짜를 접힘 밖에 직접 표시**한다(예: “2월 4일부터 입춘 이후 그해의 기운이 적용 · 7월 10일부터 10년 큰 흐름이 바뀜.”).
- **C 분야별 해석:** 종합운에서는 위 핵심 결론과 같은 문장이면 다시 쓰지 않는다. 나머지는 v11.3b 의 중요 주제 우선 + 접힘(내용 예고)을 유지. 접힘 머리글의 굵은 글씨와 예고 글 사이 공백 결함 수정.
- **D 시기별·월별 흐름 / E 전체 해석과 근거 / F 상담·저장:** 구조 유지(기본 접힘 근거, 후속 질문·저장 동작 그대로).

## 4. 문장·정확성 수정
- `period_reasons`(explain): 기간이 여러 구간에 걸칠 때 **구간마다 증거를 보고** 들여온 기운이 같은 구간끼리 묶어 문장을 따로 만든다(전에는 첫 구간의 증거로 전체를 설명). `period_reason` 은 호환용으로 유지.
- `why.period` 의 관계 문장 두 개는 한 덩어리로 잇지 않고 한 문장씩 둔다. 170자 이상 `why` 항목: **27 → 9건, 최대 219 → 180자**(합성 명식 12개 × 5개 연도).
- `months.py`: 입춘 절입 시각이 정오 이후이면 월 계산(정오 기준)과 연간 구간(절입 날짜 기준)의 시작일이 하루 달랐다(24건). 엔진은 바꾸지 않고 해당 월 항목에 **하루 차이 이유를 설명하는 안내(`notes`)** 를 추가(24건 모두 설명됨).
- 판정·톤·헤드라인 300개 항목 동일, 문장 속 날짜 범위가 엔진 구간 경계와 어긋난 곳 0건.

## 5. 테스트가 바뀐 곳(옛 디자인 가정)
콘텐츠 폭(≥72% → 960~1080px), 바탕·글자색 토큰, ‘민트/블루 없음’(의도한 옥색 토큰 허용), 섹션 제목 최소 크기(24 → 21px), 종합운 패널 헤드라인(핵심 결론에 있으면 생략), 주요 변화 요약(구간 날짜 문장 허용), 문장 하나 안의 기운 중복(기간별 문장 분리).
