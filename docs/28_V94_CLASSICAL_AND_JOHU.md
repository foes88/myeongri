# v9.4 고전 근거와 조후 해석 — 조사와 결정

> 결론부터: **궁통보감의 본문·일간×월지 표는 저장소에 넣지 않았다.** 판본과 사용 권한이 확인되지 않았기 때문이다. 대신 원문 확인이 끝난 원칙(한난 방향)에서 나오는 점검 하나를 추가했고, 그 점검이 구현자 수준임을 화면에 밝힌다. 고전 규칙을 늘리는 것과 해석 품질이 좋아지는 것은 별개이며, 이번 추가가 사건 구별에 도움이 되는지는 사례 검증으로만 알 수 있다.

## 1. 37개 규칙의 현황 (자세한 표는 `24_V91_CLASSICAL_AUDIT.md`, 자동 생성)
- 원문 24 / 후대 주석 3 / 구현자 규약 6 / 미확인 4(위치만 확인: 득령-본기 기준, 형, 파, 해).
- 일부 조건만 확인(범위 한정) 4: 득령-계절 기준(생(生) 확장 미확인), 방합(2글자 부분), 합화(쟁합·극신 조건), 격국-본기 병렬.
- 규칙별 전제 조건(학파·적용 범위)을 표에 추가했다. 전사본 호스트는 `libokang.com`(子平真詮評註), `zh.wikisource.org`(滴天髓·三命通會 등)이며 **모두 판본 교감 전**이다.
- 형·파·해는 위치만 확인된 규칙이므로 v9.2부터 방향 판정(S/T)에 쓰지 않고 '참고'로만 남긴다.

### 결정
1. 본문과 120개 표는 수집·복제·재배포하지 않는다. 사용 권한이 확인되지 않은 자료이기 때문이다. 한글 번역서도 인용하지 않는다.
2. 단순한 10×12 고정 문장표로 만들지 않는다. 조후는 **일간×월지 표가 아니라 '한난 방향 + 원국에 필요한 기운이 드러나 있는가'**로만 쓴다(滴天髓 寒暖論, 범위 한정 — 원문 확인됨).
3. 나중에 궁통보감을 쓰려면 아래 조건을 먼저 채운다.
   - 판본 확정(어느 간행본·평주본인지), 이용 권한 확인(보호기간·전사본 약관).
   - 각 항목을 규칙으로 등록: `출처·판본·조건·예외·확인 상태(원문/후대 주석/구현자 규약)`. 원문과 평주를 구분한다.
   - 사람이 짧은 발췌를 읽고 확인한 항목만 `text_confirmed` 로 올린다. 확인되지 않은 항목은 '추정(구현자 규약)'으로 표시하고 방향 판정에는 쓰지 않는다.
   - 추가 후 사례 검증(개발/검증 분리)에서 구별 능력이 오르는지 본 뒤에만 기본 화면에 반영한다.

## 3. 이번에 추가한 점검 — 계절 균형(한난)
- 태어난 달의 계절이 한쪽으로 치우친(추움·더움) 명식에서, 滴天髓 寒暖論의 방향(추우면 따뜻하게 하는 기운, 더우면 식혀 주는 기운)에 해당하는 오행이 **원국에 겉으로 드러나 있는지**(천간·지지 본기 집계, 사실)를 쉬운 말로 알려 준다. 속에 숨은 기운(지장간)은 이 점검에 넣지 않았음을 문장에 밝힌다.
- '드러나 있는가'를 기준으로 삼은 것은 구현자의 선택이다. "일반 원칙 수준이며 개별 표는 쓰지 않았다"는 조건 문구가 항상 함께 나온다.
- 한난이 한쪽으로 치우치지 않은 달(봄·가을)에는 점검하지 않는다.
- 이 점검은 판정(S/T)에 영향을 주지 않고 **종합 통변의 근거 설명**에만 쓰인다. 해석의 방향을 바꾸지 않으므로 분포 지표는 변하지 않는다.

## 4. 남은 일(차단)
- 궁통보감 판본·권리 확인은 이 환경에서 끝낼 수 없다(도서관·출판사 확인 필요).
- 미확인 4개·일부 확인 4개 규칙의 원문 대조는 사람이 판본을 읽는 작업이 필요하다.
