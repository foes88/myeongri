# AI 통변 / 출처 규약
- 10단계 순서: 명식 검증 → 일간·월령 → 통근·투간 → 세력·기세 → 격국 → 조후 → 용신 후보 → 합충형파해 → 대운·세운 → 종합 통변.
- 모든 문장은 `claim`, `rule_ids`, `source_title`, `source_location`, `source_url`, `confidence`, `exclusions` 필드를 가진다.
- 원전·주석가·현대 유추를 분리한다. 직접 검증된 고전 원문이 없으면 인용 불가로 처리.
- 양립 불가능한 학파 해석은 비교 탭에 둘 다 보여주고 하나로 합치지 않는다.
- 해석은 가능성 표현 사용. 임신·사망·질병·투자 수익·승진 시점 확정 금지. 건강 관련 정보는 의학 진료 대체 불가.
- 결과 캐시 키: 계산기 버전, 입력 해시(서버 보관 피함), 계산 정책, 규칙 버전, 모델 버전. 개인정보 로깅 금지.
- JSON schema 검증 + citation URL 화이트리스트 + 클레임/근거 매핑이 비어 있으면 재생성 또는 근거부족 처리.
- `knowledge/10_AI_사주분석_규칙.md`를 우선 준수.
