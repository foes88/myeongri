# 명리 明理 v11.0 Personal Release Candidate — 기준 안내서

> 이 문서가 현재 상태의 기준입니다. 이전 버전 문서(23~34)는 개별 변경의 상세 기록으로 남깁니다.
> **판정:** A 기능 구현 완료 ✔ · B 개인용 사용 가능 ✔(로컬) · **C 상담 품질 검증 완료 ✘ — 미검증/미평가**

## 1. 제품 목적
일반 사용자가 자신의 사주를 입력하고, 타고난 구조와 연도별·월별 흐름을 이해하고, 궁금한 것을 질문한 뒤, 결과를 저장하고 다시 볼 수 있는 **개인용** 명리 상담 서비스. 전통 명리 해석의 틀을 쉬운 말로 보여 줄 뿐, 미래 사건을 알려 주거나 보장하지 않는다.

## 2. 주요 기능
입력(기본값은 저장소 밖 로컬 파일) → 네 기둥(해·달·날·시각, 오행 색·글자, 나의 중심) → 핵심 결론 → 내 사주의 모습(자연물 비유·오행 순환도·계절 균형·십성 풀이) → 시기별 흐름(1·5·10년 타임라인, 분야×연도 표, 연도 심화 풀이) → **월별 흐름(절기 12구간)** → 분야별 해석 → 후속 질문(연도·**월**·분야 맥락) → 저장·재열람·내보내기·삭제(회원).

## 3. 사용자 흐름
회원 로그인 → 입력 → 결과 → 연도 변경/5·10년 비교 → 월별 흐름 열기·월 선택·이전/다음 달(해 경계 넘어 이동) → 분야 선택 → 후속 질문(칩 또는 직접) → 저장 → 로그아웃 → 재로그인 → 재열람 → 내보내기 → 삭제. 화면에서 지금 보고 있는 것(연도·월·분야)이 ‘지금 보고 있는 것’ 줄에 표시되고 질문의 기본 맥락이 된다.

## 4. 기술 구성
FastAPI(`backend/app`) + 정적 웹(`web/`, 번들러 없음, Motion 14.9.0 고정·해시 검증) + PostgreSQL(Docker `myeongri-pg`, 개인용 127.0.0.1:55498). 계산 Astro-Core V2 → 해석 Mingli L1~L5 → `app/consult/*`(judge-2.0.0 판정, profile-1.0.0 종합 통변, sipsung-1.0.0, months-1.0.0). 개인 데이터는 앱 키로 암호화 저장.

## 5. 사주 계산 범위
양·음력, 절입·대운·세운·월운, 시간 보정(표준시/지방평균태양시)과 시주 불확실성(변형 후보) 표시. 1901~2049. 독립 교차검산은 일부만 완료(검증 완료로 표시하지 않음, 화면에 계산 상태 안내).

## 6. 해석 엔진 범위
구조 판정(기회/주의/양면/근거 부족/변화 없음/안정)은 연도·분야 단위. 규칙은 구현자 규약이며 고전 원문 대조 전이다. 새 십성·궁위·월별 길흉 규칙은 이번 버전에서 **추가하지 않았다.**

## 7. 연도별 분석
핵심 결론 → 자세한 풀이(타고난 사주/달라지는 조건/주제/입춘·큰 흐름 구간/분야별/반대 근거와 한계) → 현실에서 생각해 볼 점. 종합운 탭이 열려 있으면 아래 분야 패널과 겹치는 문단은 생략한다.

## 8. 월별 분석 (months-1.0.0)
엔진 월운 결과를 쉬운 말로: 실제 절입 구간(날짜·시각), 월의 기운, 원국과의 관계(형·파·해·시주 불확실 시 ‘참고용’), 분야별 구조 변화(‘더해짐/커짐’만). **월별 기회·주의 판정 없음**(`direction=None`, 화면·질문 답변에 사유 명시). 절입 시각을 독립 라이브러리와 대조(2분 이내, 4개 연도 ≥30건). 입춘·대운 교체 경계 처리. 월별 정보가 없는 상담(옛 저장본·범위 밖)은 안내 문구를 보인다.

## 9. 후속 상담
규칙 기반(LLM 미사용). 지원: 의미 설명, 이유(왜), 비교(연도·월), 고려할 점, 분야 상세, 관계, 월 질문(“3월은?”, “이 달과 지난달은?”, “5월 재물운”, “왜 이 달에 변화가?”). 우선순위: **질문에 적은 연도·월·분야 > 화면에서 선택한 것 > 직전 답변 맥락**. 질문에 없는 월은 만들지 않고, 월이 필요한데 선택이 없으면 되묻는다. 달력 ‘3월’이 절기 구간 둘에 걸치면 둘 다 설명한다. 월 질문은 ‘월별 사실’과 ‘해 전체 해석’을 구분해 답하고 월별 길흉 판정이 없음을 밝힌다. **자유 대화형 AI 상담은 모델이 연결되지 않아 미구현**(완성이라 표시하지 않음).

## 10. 회원 및 개인정보
가입 모드 open/invite/closed(개인용은 closed), 로그인 속도 제한, 세션 만료, 사용자별 격리(타인 접근 404), 저장본에 출생 입력 미포함, 이메일·본문 암호화, 삭제 시 연쇄 제거, 로그아웃 시 화면 데이터 제거. 실제 출생정보는 `~/.myeongri/defaults.json`(저장소 밖)에만 있고 루프백에서만 제공. Git 이력에서 실제 출생정보 0건(공개 저장소 `main` 1개 브랜치).

## 11. 검증 완료 항목 (자동·브라우저)
- 백엔드 전체(최종 수치는 §15), 브라우저 96개(5개 폭·접근성·움직임 줄이기·라이브러리 차단·월별·맥락 통합), PostgreSQL 12개(임시 DB로 별도 실행, 통과).
- 월별: 구간 연속·빈틈 없음, 절입 시각 독립 대조, 입춘 경계, 방향 필드 없음, 요청 분야만, 경로별 동일 결과, verdict 불변, 개인정보 없음.
- 월 질문 11개(우선순위·충돌·범위 밖·회원 저장/재열람/격리).

## 12. 미검증 항목
- **상담 품질(해석의 타당성·미래 예측 능력): 실제 사례 0건, 사람 평가 0건 → 미검증/미평가.**
- 월운 해석·구조 변화 규칙: 고전 대조 전, 적용 범위 미검증.
- Astro-Core 일부 독립 검증 미완료(계산 상태 안내로 표시).
- 움직임·화면 개선이 이해도·만족도를 높였는지: 미평가.

## 13. 알려진 제한사항
- 풀이 문장은 엔진 템플릿 기반이라 모호한 표현이 많고(합성 12명식 측정: 모호 표현 문장 비율 약 33%) 같은 명식 안에서 문장 반복이 크며(연도·분야 간 중복 60%, 타고난 사주 설명이 연도마다 같은 것이 주원인), 서로 다른 명식 사이에서도 ‘현실에서 생각해 볼 점’ 같은 일반 조언 문장 57개가 절반 이상의 명식에서 같다. 문장 다양화는 엔진 문구 확장이 필요해 이번 범위에서 하지 않았다(측정: `python -m tools.text_probe`; 예측 정확성과 무관).
- 월별 방향성 없음, 월 질문은 규칙 기반이라 지원 형식 밖은 “지원하지 않음”으로 답한다.
- 옛 저장 상담에는 월별 흐름이 없어 ‘다시 분석’이 필요하다.
- 1년 보기는 정보가 한 칸이라 휑하다(폭만 줄였다).
- 운영(Vercel)은 계정 기능이 꺼져 있고 일회성 분석만 된다(영구 DB 없음).

## 14. 로컬 실행 / 테스트
- 최초 1회 `scripts\create-owner.bat`, 실행 `scripts\run-local.bat` → `http://127.0.0.1:8765/consult.html`(Docker 필요).
- 테스트: `cd backend && python -m pytest -q`(백엔드), `python -m pytest -m browser tests/browser -q`(브라우저, playwright+chromium), PostgreSQL 은 임시 DB 를 만들어 `PG_TEST_URL` 지정 후 `tests/test_v72_accounts.py`.
- skip 분류: 기본 실행에서 브라우저 96개(별도 `-m browser` 로 실행·통과), PostgreSQL 12개(`PG_TEST_URL` 필요; 임시 DB 로 실행·통과). 사유 없는 skip 0.
- 풀이 문장 점검: `python -m tools.text_probe`, 월별/후속 질문 확인은 `tests/test_v103_months.py`, `tests/test_v110_month_qa.py`.

## 16. 개인용 사용 가능 여부
**가능(로컬).** 입력·결과·연도/월 탐색·질문·저장·재방문·삭제가 동작하고 자동·브라우저·PostgreSQL 테스트가 통과한다. 단 해석의 타당성은 검증되지 않았으므로 ‘참고용’으로만 쓴다.

## 17. 일반 공개·상용화 차단 요건
1. 실제 사례 검증(`tools.case_eval`)과 사람 평가(`tools.blind_eval --set v96`)에서 사전 정의 기준 충족 — **미충족(0건)**.
2. 월별·구조 규칙의 고전 대조 및 적용 범위 검증.
3. 계산 독립 검증 완료(Astro-Core).
4. 운영용 관리형 PostgreSQL·백업·비밀 관리·약관/개인정보 처리방침·동의·내보내기 안내·모니터링.
5. 자유 대화형 상담을 제공한다면 모델 연결과 별도 안전 검증.
6. GitHub에 남은 옛 커밋 SHA 캐시 삭제 요청(지원 요청 필요), Vercel 과거 프리뷰 배포 정리.
