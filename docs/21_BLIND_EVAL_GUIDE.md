# 블라인드 평가 파일럿 — 평가자 안내와 운영 방법

> 상태: **미평가**(응답 0건). 이 문서의 평가는 아직 수행되지 않았다. 파일럿은 표본이 작아 통계적 결론이 아니며, 파일럿이 끝나도 ‘상담 품질 검증 완료’로 표시하지 않는다.

## 1. 무엇을 비교하나
합성(가상) 명식 20개에 같은 질문을 넣어 서로 다른 세 가지 방식으로 만든 상담 문장(v7.0 종합 템플릿 / v8.1 결론형 / v8.2 개선형)을 **출처를 가린 채**(문장 X·Y·Z, 순서는 항목마다 무작위) 평가한다. 실제 사람의 출생정보는 쓰지 않는다.

## 2. 평가자에게 보낼 것 (이 파일 하나)
`backend/data_private/blind/rater_form.html` — 독립 HTML 한 개(외부 파일·서버 전송 없음). 이메일·메신저로 전달하고, 받은 사람이 브라우저로 열어 평가한 뒤 **‘평가 결과 내려받기(CSV)’** 로 만든 CSV 파일을 운영자에게 보낸다. **`key.json` 은 절대 보내지 않는다**(어느 문장이 어느 방식인지 적혀 있음).

### 평가자 안내문 (폼 첫 화면에 같은 내용이 들어 있음)
> 명리학을 몰라도 됩니다. 아래 문장은 가상의 사주(실제 사람이 아님)로 컴퓨터가 만든 상담 문장입니다. 항목마다 서로 다른 방식의 문장 X·Y·Z가 나오며 어느 방식인지는 알려 드리지 않습니다. 정답은 없으니 읽고 느낀 대로 평가해 주세요.
> 1. 질문을 읽고 문장 X·Y·Z를 읽습니다.
> 2. 문장마다 **이해도 · 구체성 · 유용성 · 자연스러움 · 신뢰도**를 1(전혀 아니다)~5(매우 그렇다)로 고릅니다.
> 3. 가장 마음에 드는 문장을 고르고 **이유를 한두 문장**으로 적어 주세요(선택).
> 4. 10개 이상 평가하면 충분합니다. 입력은 브라우저에 자동 저장됩니다.
> 5. 실제 이름·생년월일·연락처는 적지 말고 별명/번호만 쓰세요.

| 항목 | 뜻 |
|---|---|
| 이해도 | 읽고 내용을 이해할 수 있다 |
| 구체성 | 내 사주·그 시기에 맞는 구체적인 설명이다 |
| 유용성 | 내 질문에 답이 되고 생각해 볼 거리를 준다 |
| 자연스러움 | 사람이 쓴 듯 읽기 편하다(같은 말의 반복·어색함 없음) |
| 신뢰도 | 근거 없이 단정하지 않고 믿을 만하다 |

## 3. 응답 집계
```
python -m tools.blind_eval score 받은_파일1.csv 받은_파일2.csv ...   # 집계 + summary.md / summary.csv 저장
python -m tools.blind_eval status                                    # 응답 없이 현재 상태(미평가) 확인
```
- 버전별 항목 평균, 선호 수, 선호 이유, 평가자 간 선호 일치도를 낸다. 값이 잘못된 응답(1~5 밖, 알 수 없는 항목)은 집계에서 제외하고 사유를 남긴다.
- **상태**: 응답 0건 → `미평가` / 평가자 5명 미만·10항목 미만·중복 평가 없음 → `진행 중` / 5명·10항목·중복 충족 → `파일럿 완료(예비 결과)`.
- **상담 품질 검증 완료**는 별도 기준(전문가 3명 + 일반 3명 이상, 각 10항목 이상)이며, 파일럿 완료와 다르다. 어떤 경우에도 자동 지표만으로 완료로 기록하지 않는다.

## 4. 패킷 다시 만들기
```
python -m tools.blind_eval build --n 20 --v81-json data_private/blind_v81.json --v82-json data_private/blind_v82.json
```
이전 버전 문장은 해당 커밋의 코드에서 `python -m tools.dump_verdict_text OUT.json` 으로 덤프한다(v8.1=ecbc6c3, v8.2=59c4e0a).
