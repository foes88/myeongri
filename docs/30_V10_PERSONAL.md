## 화면이 답하는 6가지 질문 (접힌 것을 펼치지 않고)
1. 이 사주에서 무엇이 중요하게 읽히는가 → 종합 통변 결론
2. 올해(선택한 시기) 어떤 조건이 달라지는가 → 종합 통변 "선택한 시기에 달라지는 조건"
3. 직업과 재물에는 각각 어떤 의미가 있는가 → 분야별 블록(연도 상세)
4. 어떤 해를 더 주목할 만한가 → 시기별 핵심 흐름·★ 표시(구조 변화의 크기 기준, 확률 아님)
5. 왜 그렇게 읽는가 → "왜 그렇게 읽나요?"(종합·분야별)
6. 판단 근거가 부족한 부분은 무엇인가 → "근거가 부족해 판단을 유보한 분야" + 조건 상자
실제 사건 발생을 확정하는 표현은 쓰지 않는다(테스트로 확인).

## 상태 구분(섞지 않는다)
- **계산 검증**: 천문 계산 교차 일치 여부와 미완료 항목을 화면에 쉬운 말로 표시. Astro-Core V1 승인 아님(V2).
- **고전 규칙**: 37개 중 원문 24·후대 주석 3·구현자 규약 6·미확인 4(`24_V91_CLASSICAL_AUDIT.md`).
- **자동 지표**(합성 명식, 사건 없음): 판정 분포·구별 가능성(`26_V92_JUDGE.md`). 해석 정확도가 아니다.
- **실제 사례 검증**: 실제 사례 0건 → 미검증.
- **사람 평가**: 응답 0건 → 미평가. 본인 평가 기록은 개인 사용 기록이며 품질 검증이 아니다.
- **사용성 검증**: 실제 사용 평가 전 → "검증 완료"로 표시하지 않는다.

## 읽는 순서(화면 정보의 우선순위) — v10.0 후속 수정
첫 장면을 이야기로 바꿨더니 모바일에서 핵심 결론이 두 화면 아래로 밀렸다. 결론이 먼저 보이도록 순서를 다시 정했다. 해석 규칙·판정 로직·결과 내용은 바꾸지 않았다.
1. **이 사주에서 중요하게 읽히는 것**(핵심 결론) — 360px 첫 화면(800px) 안에 온전히 보인다(브라우저 테스트로 검증).
2. **선택한 시기의 주요 변화와 분야별 요약** — 여러 해: 시기별 핵심 흐름 + 분야×연도 한눈표 + 연도별 한 줄 / 한 해: 분야별 풀이.
3. **이 사주를 자연에 빗대면 ‘○○에 선 △△’** — 제목과 "비유일 뿐 근거가 아니다"라는 설명만 보인다.
4. 기본 접힘: **오행 분포 막대 · 계절 균형(필요한 기운) · 큰 흐름과 해당 연도의 기운 표**("기운 분포·계절 균형·큰 흐름 표 보기").
5. 한계 안내.

### 자연물 비유와 '필요한 기운'의 위치
- 자연물 비유와 필요한 기운 표는 **설명용**이다. 판정(S/T·톤)과 종합 통변 문장에 어떤 값도 넘기지 않는다. 테스트: 비유를 없애거나, 필요한 기운이 모든 해에 들어오거나 하나도 안 들어오게 바꿔도 모든 분야 판정과 문장이 같다.
- **'필요한 기운이 들어온다 = 좋은 운'이 아니다.** 화면에 "좋은 운이라는 뜻이 아니라 계절 균형의 참고 표시"라고 밝히고, 필요한 기운이 들어오는 해에도 '기회' 아닌 판정이 나오는 비율을 테스트로 확인한다(두 판단이 독립). 설명 문구에 행운·길운 등 표현이 나오지 않는지도 검사한다.
- 비유 사전과 필요한 기운 점검은 구현자 수준의 표현이며 원문 대조를 마치지 않았다.
- 이 순서가 읽는 경험을 실제로 개선했는지는 사람 평가(v9.6 도구)로만 알 수 있다. 지금은 미평가다.
