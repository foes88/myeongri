# v10.0 개인용 고품질 상담 통합

v9.2~v9.6에서 실제로 바뀐 것만 개인용 앱(v9.0)에 통합했다. 기존 기능(회원·본인 저장·연도 이동·5/10년·후속 질문·재열람·삭제·암호화·계산 상태 안내·명리 서재 디자인)은 그대로이며 브라우저 E2E로 계속 확인한다.

## 화면이 답하는 6가지 질문 (접힌 것을 펼치지 않고)
1. 이 사주에서 무엇이 중요하게 읽히는가 → 종합 통변 결론
2. 올해(선택한 시기) 어떤 조건이 달라지는가 → 종합 통변 "선택한 시기에 달라지는 조건"
3. 직업과 재물에는 각각 어떤 의미가 있는가 → 분야별 블록(연도 상세)
4. 어떤 해를 더 주목할 만한가 → 시기별 핵심 흐름·★ 표시(구조 변화의 크기 기준, 확률 아님)
5. 왜 그렇게 읽는가 → "왜 그렇게 읽나요?"(종합·분야별)
6. 판단 근거가 부족한 부분은 무엇인가 → "근거가 부족해 판단을 유보한 분야" + 조건 상자
실제 사건 발생을 확정하는 표현은 쓰지 않는다(테스트로 확인).

## 상태 구분(섞지 않는다)
- **계산 검증**: 천문 계산 교차 일치 여부와 미완료 항목을 화면에 쉬운 말로 표시. Astro-Core V1 승인 아님(V2).
- **고전 규칙**: 37개 중 원문 24·후대 주석 3·구현자 규약 6·미확인 4(`24_V91_CLASSICAL_AUDIT.md`).
- **자동 지표**(합성 명식, 사건 없음): 판정 분포·구별 가능성(`26_V92_JUDGE.md`). 해석 정확도가 아니다.
- **실제 사례 검증**: 실제 사례 0건 → 미검증.
- **사람 평가**: 응답 0건 → 미평가. 본인 평가 기록은 개인 사용 기록이며 품질 검증이 아니다.
- **사용성 검증**: 실제 사용 평가 전 → "검증 완료"로 표시하지 않는다.

## 읽는 흐름(첫 화면 구성) — v10.0 후속
사용자 피드백("결과를 흐름대로 보면서 '이거군' 하고 이해되고 흥미가 생기는 결과가 아니다")에 따라 결과의 순서를 이야기로 바꿨다.
1. **첫 장면(이야기 카드)**: "이 사주를 자연에 빗대면 ‘겨울에 선 큰 나무’" — 태어난 날의 글자(일간)를 자연물에 빗대고 태어난 계절을 붙인다. 이어서 타고난 기운 분포(막대), 계절에 필요한 기운, 선택한 시기에 그 기운이 들어오는 때(10년 큰 흐름 ●/○, 그해 ●/○)를 시간 순서로 보여 준다.
2. 이 사주에서 중요하게 읽히는 것(핵심 결론 → 현실 참고 → 접힌 이유·조건)
3. 시기별 핵심 흐름 + **분야×연도 한눈표**(기호·글자·색을 함께 사용, 확률이 아님을 범례에 명시) + 연도별 한 줄
4. 분야별 풀이

### 정직성 장치
- 자연물 비유(일간 물상)와 ‘필요한 기운’ 점검은 **전통의 설명 방식을 쉽게 푼 구현자 수준의 표현**이며 원문 대조를 마치지 않았다. 카드 안에 "성격이나 일어날 일을 말하는 것이 아니며, 일간별 계절 표(궁통보감)는 쓰지 않은 일반 원칙 수준의 참고"라고 밝힌다.
- 이야기 카드는 판정(기회·주의 등)에 영향을 주지 않는다. 사실(글자 수·계절·대운/세운 글자의 기운)을 시간 순으로 배치한 것이다.
- 흥미를 위해 없는 내용을 만들지 않는다. 한 구조가 뚜렷하지 않으면 그렇게 말하고, 이야기 카드가 그 빈자리를 사실 기반의 그림으로 채운다.
- 이 변경이 이해도·흥미를 높였는지는 **사람 평가(v9.6 도구)로만 알 수 있다.** 지금은 미평가다.
