## 판매 가능 상태의 정의 (Release Gates)
아래를 **전부** 만족하기 전에는 유료 보고서를 생성·판매하지 않는다. 현재 상태는 2026-10-29 기준.

| # | 게이트 | 기준 | 현재 |
|---|---|---|---|
| G1 | 명식 계산 검증 | `verification_levels.v1_allowed()` 가 True (4개 레벨 + 필수 자료 4종 + 라이선스) | ❌ 차단 (PILLARS/PROFILE/DAEUN/LUNAR 미부여, 라이선스 미확인) |
| G2 | 해석 엔진 | Mingli-Graph 1~5층 + 근거 노드 자동 검사 통과 | ◐ 1~5층 구현, 학파 평가기·사례 DB·상담 에이전트 없음 |
| G3 | 고전 근거 | 규칙의 `classical_verification` 이 pending 이 아님 | ❌ 전 규칙 pending |
| G4 | 상담 품질 | Eval Track A 블라인드 평가 수행·결과 보고 | ❌ 미수행 |
| G5 | 예측력 주장 | Track B 사전등록 검증 결과 없이 "정확/적중" 표현 금지 | ✅ 문구 금지 정책(설계), 검증 미수행 → "예측력 미확인" 고지 필수 |
| G6 | 개인정보 | 처리방침·약관·환불정책 법률 검토, 암호화·삭제·접근제어 구현과 테스트 | ❌ 미구현 |
| G7 | 결제 | 모의 결제 통합 테스트(중복·웹훅·환불·크레딧 복원) 통과 후 PG 샌드박스 | ❌ 미구현 |
| G8 | 안전 | 건강·사망·투자·승진 확정 표현 필터, 위기 상황 안내 | ◐ 텍스트 검사기(L01~L12, X01~X08) 존재, 실서비스 연결 없음 |
| G9 | 운영 | 비용 추적·오류율·재현성 모니터링·장애 대응 | ❌ 미구현 |
| G10 | 법규 | 표시광고·전자상거래법·개인정보보호법·청약철회 검토 | ❌ 미검토 |

## 불변 원칙
1. 해석 엔진이 게이트 G1·G2 를 못 넘으면 유료 보고서를 만들지 않는다. 결제는 그 이후.
2. 무료/유료 차이는 **설명의 깊이와 부가 기능**이다. 기본 명식 계산의 정확도·검증 수준은 차별하지 않는다.
3. 유료라고 예측 정확도를 보장하지 않는다. 모든 상품에 "전통 해석이며 예측력은 검증되지 않았다" 고지.
4. 사용자의 현실 상황은 선택 입력이며 사주 계산·구조 판단의 근거로 쓰지 않는다. 상담 층에서만 사용한다.
5. 개인정보는 최소 수집하고, 공개 저장소·로그·분석 이벤트에 넣지 않는다.
