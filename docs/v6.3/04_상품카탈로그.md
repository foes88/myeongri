# 무료·유료 상품 카탈로그 (설계)

## 차별 기준
- **같은 것**: 명식 계산, 검증 상태 표시, 변형 명식 고지, 근거 ID, 안전 고지. 계산 정확도·검증 수준으로 차등하지 않는다.
- **다른 것**: 설명의 깊이(분량·근거 노출 범위), 기간·분야의 폭, 추가 질문 횟수, PDF·재열람 보관 기간.
- 어떤 상품도 예측 정확도·적중을 약속하지 않는다.

## 깊이별 산출물
| depth | 포함 | 제외 |
|---|---|---|
| summary | 한국어 요약(쉬운 말), 핵심 구조 3~5개, 반대 근거 1줄씩, 용어 펼침 | 전체 근거 그래프, 학파 병렬 비교 |
| detailed | summary + 구조별 찬성·반대 근거, 격국/억부/조후 후보 분리, 대운·세운 구간 설명, 질문별 답 | 규칙 ID·원전 위치 전체 노출 |
| expert | detailed + 규칙 ID·claim 그래프·학파 충돌 목록·계산 프로필·변형 명식 비교 | — |

## 상품 (가격은 미정 — 원가 모델 확정 후 결정)
| code | 내용 | 대상 | 비고 |
|---|---|---|---|
| FREE_INTRO | 명식 + 원국 구조 summary 1회 | 신규 | 평생/월 한도 정책 필요. LLM 설명 최소(템플릿 중심) |
| OVERALL_SUMMARY | 종합운 summary | | |
| PERIOD_YEAR_{depth} | 특정 연도(대운 교체 구간 분리 포함) | | 2030 같은 연도 지정 |
| PERIOD_RANGE5/10 | 5·10년 흐름 | | 연도별 비교표(점수 없음) |
| PERIOD_COMPARE | 두 연도 비교 | | 우열 아닌 특징 대비 |
| DOMAIN_WEALTH / CAREER / DOCS_REALESTATE / LOVE / FAMILY | 분야별 detailed | | 투자·승진 확정 표현 금지 |
| HEALTH_TRADITIONAL | 전통 해석 상징만 | | 진단·치료 조언 금지, 의료 안내 고정 문구 |
| FOLLOWUP_PACK_n | 추가 질문 n회 | | 구조 JSON 변경 불가 |
| FAMILY_PACK | 최대 4인 | | 프로필 4개, 개인정보 부담 큼 |

## 이용권·크레딧
- 크레딧 1 = 분석 작업 단위 환산표(depth × 기간 폭). 소진·만료·환불 규칙은 07 문서.
- 무료 체험 한도: 계정당·기기당·월 한도(어뷰징 방지), 한도 소진 시 안내만.

## 출시 순서 제안
1. (G1·G2 통과 후) FREE_INTRO + OVERALL_SUMMARY 만 베타. 2. PERIOD_YEAR. 3. 분야/가족 팩. 건강 상품은 법률 검토 후.
