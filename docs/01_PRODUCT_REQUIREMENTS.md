# 제품 요구사항 PRD v1
목표: 이름 없는 입력도 가능하고 생년월일/음양력/윤달/시간/출생지/성별을 받아 한눈에 이해되는 고전 명리 리포트를 제공한다.

## 이용자 흐름
1. 랜딩 → [무료로 명식 확인] → 입력 폼(이름 선택, 양/음력, 윤달, 날짜, 시간 모름, 출생지 검색, 계산 프로필 선택) → 검증 오류 표시.
2. 계산기에서 근거 메타데이터 포함 명식 산출 → 사용자에게 시간대 경계 모호성 표시 및 선택 → AI 해석 시작.
3. 결과: 30초 요약 → 4주 카드 → 오행/십성/월령 → 직업/재물/문서/생활 → 대운/세운 → 사용 이론 근거 → 학파 차이.
4. 공유: 이름/생년월일/출생시각 숨김 기본값, 공유 전 미리보기, 만료 링크, 삭제/회수 기능.

## 화면
반응형 최대 폭 1160px; 모바일 단일 컬럼. 색 #F7F6F1(배경), #242F30(텍스트), #1F6760(포인트), #BE9864(보조). 본문 최소 16px, AA 색 대비. 읽는 순서: 요약→카드→상세→출처. 점수형 단정 및 불길한 공포 문구 금지.

## P0 기능
정확한 음양력/절기/시간대 계산, 프로필별 시주 비교, 근거 출처 기록, 접근성, 비저장 기본값, 유효성 검증, 재현 테스트. P1: PDF/가족 프로필/공유 링크. P2: AI 질의응답/다국어.
