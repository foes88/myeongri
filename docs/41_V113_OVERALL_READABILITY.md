# v11.3 종합운(분야 패널) 가독성 + 문장 조합 수정

> 판정·톤·헤드라인 문장은 바뀌지 않았다(합성 4개 명식 × 2개 연도에서 톤·헤드라인 동일 확인). 해석 문장 중 **조합 버그로 같은 문구가 되풀이되던 설명 문장만** 고쳤다. 이해도 개선은 **미평가**(사람 평가 0건).

## 1. 가독성 문제의 실제 원인
1. **문장 조합 버그 (`explain.period_reason`)**: 10년 큰 흐름과 그해가 같은 기운 묶음(예: 표현·기술의 기운)을 들여오는 해에도 두 쪽을 각각 나열해 “10년 큰 흐름이 들여온 A · B, 그해가 들여온 A · B”처럼 같은 문구가 두 번 나왔다. 합성 명식 4개 × 2개 연도 종합운에서 이 문장 8개 전부가 중복이었다.
2. **영역 이름 이음 방식**: “나 자신·배우자 쪽(태어난 날) · 말년·자녀 쪽(태어난 시)”처럼 영역 이름 안의 ‘·’과 영역 사이의 ‘ · ’가 구분되지 않았다.
3. **화면 구성**: 분야 패널의 첫 문장이 굵은 글씨로 크게 나가고(긴 설명 문장이 ‘요약’이 되는 경우 포함), 나머지가 칸 구분 없는 한 덩어리 문단이었다.

## 2. 변경
- **`explain.period_reason`**: 같은 기운은 “10년 큰 흐름과 그해가 함께 들여온 A”로 한 번만, 한쪽만 들여온 기운은 “10년 큰 흐름만 / 그해만 들여온 B”로 구분(겹침이 없으면 기존처럼 이·가), 이어 붙일 때 ‘과’를 연달아 쓰지 않고 “…이 모두”로 잇는다.
- **`verdict._join_areas`**: 영역 이름 사이를 ‘과’로 잇는다(“…쪽(태어난 날)과 …쪽(태어난 시)에서”).
- **`story_parts`(추가 필드)**: 엔진이 각 문장을 만든 칸(natal·period·relation·contrast·counter·timing·cross·emphasis·where)을 `story` 와 같은 순서·같은 문장으로 함께 내보낸다. 기존 `story` 는 그대로(API 호환), 옛 저장본에는 없으므로 화면이 `story` 로 대체한다. 블록 간 중복 제거 때 `story_parts` 도 동기화.
- **화면 (A→B→C)**:
  - **A 핵심 요약**: 머리 문장 최대 2문장(원문 그대로), 굵지 않게(글자 굵기 500 이하), 남는 문장은 C 에 있다.
  - **B 주제별 해석**: 실제로 있는 칸만 제목+문장(칸 이름 → 제목: 타고난 모습 / 이 해에 달라지는 조건 / 관계와 변화 / 함께 고려할 점 / 다른 견해 / 시기 참고 / 다른 분야와의 연결 / 무게가 실린 쪽 / 나타나는 영역). 문장을 쪼개거나 바꾸지 않는다. ‘관계와 변화·함께 고려할 점·다른 견해’는 제목 색(인장색)과 제목 글자로 구분(배지·테두리 추가 없음). ‘현실에서 생각해 볼 점’ 포함.
  - **C 원문과 해석 근거 보기(접힘)**: 상세 해석 원문(A 에 못 담은 문장 포함 전부) → 명리 용어 설명(응답에 용어 사전이 있을 때만) → 해석 근거(원문과 같은 문장은 다시 쓰지 않음) → 상반되는 근거와 한계.

## 3. 전후 (합성 명식, `backend/data_private/ux/v113/`)
- 문장 예(`s3-0-2027`):
  - 전: 그해 내내 10년 큰 흐름이 들여온 나와 같은 기운 · 재물·현실 자원의 기운, 그해가 들여온 재물·현실 자원의 기운이 타고난 사주의 기운과 이어지면서 …
  - 후: 그해 내내 10년 큰 흐름과 그해가 함께 들여온 재물·현실 자원의 기운, 10년 큰 흐름만 들여온 나와 같은 기운이 모두 타고난 사주의 기운과 이어지면서 …
- 같은 기운 이름이 한 문장에 두 번 나오는 ‘들여온’ 문장: 8 → 0 (8개 중).
- 화면 비교: `cmp_360_open.png`(전/후), `after_view_1440.png`.
- 보이는 글자 수(합성 5년, 접힘 상태): 1,179 → 1,564자(1440px), 1,211 → 1,576자(360px). **늘었다** — 주제별 해석(분야 패널 약 390자)이 기본으로 보이기 때문(이전 단계에서는 접혀 있었다). 요청이 ‘구분해서 훑어볼 수 있게’라 이 대가를 받아들였다.

## 4. 검증
- 백엔드 `tests/test_v113_textgen.py`(9): 같은 기운 한 번만, 다른 기운은 각자 출처, 부분 겹침, `story_parts` = `story`(모든 블록, 3개 시드), 영역 이름을 ‘ · ’로 잇지 않음, 같은 문장 안 기운 이름 중복 없음. 영향받는 기존 테스트 `test_v82_quality` 는 ‘함께 들여온’ 표현을 허용하도록 갱신.
- 브라우저 `tests/browser/test_v113_overall.py`(4): 주제는 API `story_parts` 칸에서만 나오며 같은 순서, 모든 문장 보존, 요약 굵지 않음·화면에 보이는 문장 중복 없음·같은 문장 안 기운 중복 없음, 옛 저장본(`story_parts` 없음) 호환, 주의 주제는 제목 글자로도 구분.
- 기존 원문 보존·판정 라벨 = API 판정 테스트 통과. 다른 분야·공통 패널 회귀는 전체 브라우저 테스트로 확인.

## 5. 한계
- “그해 내내 …” 설명 문장은 기운 묶음이 세 가지로 갈리면 여전히 길다(중복은 없앴지만 문장 길이 자체를 줄이진 않았다).
- 접힘 C 안에서 ‘상세 해석 원문’과 B 의 문장이 같다(원문 보존이 목적).
- ‘핵심 요약 최대 2문장’은 원문 머리 문장의 앞 두 문장이다. 사용자가 든 예시처럼 새로 다시 쓴 요약은 만들지 않았다(의미 왜곡 방지).
- 사람이 읽고 평가하지 않았다.
