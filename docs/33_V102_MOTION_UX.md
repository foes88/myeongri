# v10.2 Motion 기반 움직임 개편

> 브랜치 `feature/v10.2-motion-ux` (로컬). 이 작업은 **움직임·전환만** 다룬다. 계산·판정·문장·데이터는 바꾸지 않는다.

## 1. 왜 Motion 을 포함했나 (vendoring)
- 앱은 번들러 없이 `<script>` 로 읽는 순수 JS 이고, 보안 정책(CSP `script-src 'self'`)이 외부 주소 스크립트를 막는다. 출생정보를 다루므로 외부 호출도 없어야 한다. 그래서 Motion 을 쓰려면 **배포본 파일을 프로젝트에 넣어야** 한다.
- `web/assets/vendor/motion-14.9.0.js` — npm `motion@14.9.0` 의 `dist/motion.js`(UMD, 전역 `Motion`) 원본 그대로. MIT 라이선스 문서 `motion-LICENSE.md` 동봉.
- 크기: 179,011바이트(gzip 약 60KB). 결과 화면(`consult.html`)에서만 불러온다.
- 무결성: sha256 `08423884b313dacbd12fdaff2d002a5b862c8009c17da285a8460efad98d63c3` (테스트가 고정값과 비교 → 교체·변조 시 실패). `eval`/`new Function` 없음(CSP 충돌 없음).
- **업데이트 방법:** 격리 폴더에서 `npm pack motion@<버전>` → `dist/motion.js` 복사 → 파일명·해시·`consult.html`·테스트의 고정값 갱신 → 전체 브라우저 테스트.
- 이번 탐색은 저장소(`motiondivision/motion`)를 읽기 전용으로 살펴보았고, 그 저장소의 지침 파일(CLAUDE.md·AGENTS.md)은 따르지 않았다.

## 2. 원칙
1. 장식이 아니라 **읽는 순서와 상태 변화를 이해시키는** 움직임만.
2. 내용과 무관: `motion-ui.js` 는 opacity/transform/height 외에는 DOM 을 건드리지 않고 텍스트·데이터를 읽지도 바꾸지도 않는다(테스트: 막대 높이는 글자 수 비율 그대로, 구간 막대는 엔진 일수 비율 그대로).
3. **움직임 줄이기**(`prefers-reduced-motion`)를 켰거나 Motion 을 불러오지 못하면 아무 것도 움직이지 않으며 화면은 처음부터 완전하다(CSS 전환·누름 피드백도 꺼짐).
4. 끝나면 흔적이 없다: Motion 이 마지막 값을 인라인 스타일로 확정한 뒤(두 프레임 + 지연) 인라인 `opacity/transform` 을 모두 치운다.
5. 클릭을 막지 않는다: 텍스트는 애니메이션을 기다리지 않고 즉시 바뀐다.

## 4. 테스트 (`tests/browser/test_motion.py`, 9개)
고정 해시·라이선스·CSP / 같은 출처에서만 로드·오류 없음 / 결론이 노드보다 먼저, 종료 후 인라인 흔적 0, 막대·구간 값 불변 / 선택 시 텍스트 즉시 변경·바뀐 패널만 전환 / 움직임 줄이기에서 애니메이션 0 / 라이브러리 차단 시 화면 완전·오류 없음 / 새 기록 / 고정 바 그림자 / 입력 화면 정리. 기존 76개와 합쳐 **브라우저 85개 통과**, 백엔드 1080개 통과.

## 5. 한계
- 지금 포함한 배포본은 전체 번들이라 필요한 기능(animate·stagger·inView)에 비해 크다(gzip 약 60KB). 필요한 부분만 뽑은 빌드는 별도 빌드 도구가 필요해 이번에는 하지 않았다.
- 움직임이 읽기 쉬움이나 만족도를 높였는지는 사람 평가가 없어 **미평가**다.
- 입력 화면(index.html 샘플 리포트 페이지 포함)의 구조는 바꾸지 않았다. 샘플 페이지는 빌드 스크립트로 생성되어 이번 범위에서 제외했다.

## 6. 정체성 연출 추가 (사주 풀이에 맞춘 화려함)
| 연출 | 동작 | 의미 |
|---|---|---|
| 인장 | 결론 카드 오른쪽 위에 붉은 도장이 크게 내려와 ‘찍힘’(약 0.55초) | 명리 서재의 정체성, 결론 확정감 |
| 붓 밑줄 | 결론 아래에 붓이 왼쪽에서 오른쪽으로 그어짐 | 핵심 문장 강조 |
| ★ 반짝 | 가장 달라지는 해의 ★ 가 커졌다 자리잡음 | 주목할 해 표시 |
| 선택 표시 이동 | 연도를 고르면 인장색 테두리가 이전 해에서 새 해로 미끄러짐(0.42초) | 무엇이 선택됐는지 눈으로 따라가기 |
| 먹 번짐 | 해 패널이 선택한 노드 자리에서 둥글게 퍼지며 열림(0.55초) | 선택과 결과의 연결 |
| 한지 질감 | 결론 카드 배경에 아주 옅은 결·빛(CSS) | 서재 분위기 |
- 모두 장식(`aria-hidden`)이며 텍스트·데이터·판정과 무관하다. 인장 글자는 장식용 상표 표기이다.
- 움직임 줄이기·Motion 로드 실패 시 인장·붓 밑줄은 최종 상태로 정지해 보이고 이동·번짐·반짝은 없다. 끝난 뒤 인라인 `opacity/transform/clip-path` 와 임시 요소(`.tl-ghost`)는 남지 않는다.
- 테스트 추가 2개(총 11개): 연출 종료 후 흔적 0·가로 넘침 없음, 움직임 줄이기에서 비활성. 브라우저 전체 87개 통과 예상(이 절 추가 전 85개 통과 확인).
- 미평가: 이 연출이 이해·흥미를 높이는지는 사람 평가가 없다.

## 7. 강조·가독성 2차 (화려함 추가)
- **형광펜:** 결론 문장의 ‘…’ 핵심 구절에 노란 밑칠이 왼쪽에서 번짐. 글자(textContent)는 그대로이며 `<mark>` 로 감싸기만 한다.
- **상생 순환도:** 나무→불→흙→쇠→물→나무 순환도. 원 크기=글자 수, 원이 차례로 커지고 화살표가 이어서 그려짐. 장식·보조이며(`aria-hidden`) 값은 아래 막대와 접근성 라벨이 그대로 전한다. 오행 색은 색만이 아니라 글자·숫자도 함께 표시.
- **호버·선택 부각:** 타임라인 노드가 살짝 떠오르고 선택된 노드는 인장색 그림자, 표 칸 호버 테두리.
- 움직임 줄이기·로드 실패 시 모두 최종 상태로 정지. 브라우저 전체 87개 통과. 사람 평가는 여전히 미평가.
