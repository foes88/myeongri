# UI/UX 상세 명세
화면 A 랜딩: hero + ‘1분 만에 명식 확인’ CTA, 고전 출처 강조, 과장된 미래예측 금지.
화면 B 입력: 이름(선택), 날짜, 달력/윤달, 출생시각(모름 허용), 태어난 장소(현 거주지 아님!), 성별(전통 대운 계산 목적), 개인정보 동의는 저장/공유 시 별도. 출생지 autocomplete와 수동 입력 제공.
화면 C 계산 결과: 4주 명식 한자/한글/십성, 월령/통근/절기, 계산 프로필 chip, 시주 비교, 신뢰도 경고.
화면 D 해석: [핵심 요약] [직업·승진] [재물] [문서] [생활·건강] [대운] [근거]. 각 섹션 요약 2문장 + 자세히 보기; 근거 인용+학파차이.
화면 E 공유: 개인식별 항목 기본 가림, 생성 전 프리뷰, 만료 기간 선택, 재발급/회수. 개인정보 공개 전 사용자 명시 동의.
화면 F 오류: 미래·잘못된 날짜, 절기 경계, 음력 윤달 오류, 출생시 미상, AI 실패, 계산 미검증.
모바일: 입력 컨트롤 44px 터치 영역, 한자 명식 2x2 그리드, 고정 하단 CTA, 스크롤 중에도 계산 방식 알림. PC: 좌측 목차+오른쪽 카드.
공유 시 이름/정확한 출생정보 노출을 기본으로 하지 않음. 인쇄 CSS와 캡처용 1080px 카드 제공.
