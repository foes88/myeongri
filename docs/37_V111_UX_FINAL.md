# v11.1 최종 UI/UX 마감

> 계산·판정·해석 문장·월별·후속 질문 로직은 바꾸지 않았다(표시 계층만). 브랜치 `feature/v11-ux-final-polish`.
> 자동 테스트 통과와 실제 사용성 검증은 다르다: **이해도 개선은 미평가**(사람 평가 0건).

## 1. 해결한 문제
| 문제 | 조치 |
|---|---|
| 좌측 ‘내 사주의 모습’의 독립 세로 스크롤·고정 | 좌우 분할을 없애고 **가로 띠**로 바꿈. `position: sticky`·`max-height`·`overflow` 규칙 삭제(숨기지 않고 제거). 내용은 자르거나 줄이지 않음 |
| 좌측 아래 큰 빈 공간 | 띠 두 칸(비유·오행 구성 / 계절·성향) 뒤에 바로 시기별 흐름이 이어짐 |
| 본문이 작고 밀집 | 본문 17px·행간 1.8, 문단 간격 확대, 결론 20~24px, 섹션 제목 24~30px. 한 줄 길이는 CSS 본문 폭(`max-width: 42em`)이며 문장 중간 개행·`<br>` 없음 |
| 1년 보기에 한 칸짜리 타임라인·비교표 | 1년: 타임라인·표 제거 → ‘이 해의 풀이’(핵심 결론·분야별 핵심·월별 흐름). 5년: 타임라인+표 유지. 10년: 압축 타임라인+표 |
| 모드 전환 시 맥락 유실 | 1·5·10년 전환은 선택한 **연도·분야·열어 둔 월**을 유지, 이전/다음 해는 선택 연도가 함께 이동 |
| 같은 해석 반복 | 종합운 탭의 머리 문장·본문 문장 중 해 패널에 이미 있는 것은 다시 쓰지 않음(`data-deduped`). 지운 문장은 모두 해 패널에 있어야 한다는 테스트. 다른 분야는 아무 것도 지우지 않음 |
| 오행 두 시각화의 역할 | 막대(기본 노출): ‘글자 수를 센 것이며 강약·운세 점수가 아님’ 설명. 순환도: ‘오행이 서로 돕는 관계 알아보기’로 **접은 보조 설명**, 원 크기 동일. 막대·순환도 숫자 일치 및 네 기둥 글자 수와의 합 일치 테스트 |
| 분야 탐색 | 탭을 크고 선택 상태를 강하게(배경+굵은 글자+밑줄), 표 칸·‘분야별로 읽으면’ 클릭 시 분야 상세로 부드럽게 이동(이미 보이면 이동 안 함, 움직임 줄이기는 즉시) |
| 후속 질문·저장 | 큰 카드 → 간결한 패딩·제목, 입력창 크기 조정, 이메일/비밀번호 정렬. 회원·저장·삭제·내보내기 기능은 그대로 |
