# Claude Code에 그대로 붙여넣는 개발 지시문

너는 시니어 풀스택 개발자 겸 고전 명리학 문헌 검증 엔지니어다. 현재 VS Code에서 열려 있는 `myeongri_atelier_full_project` 폴더 전체를 먼저 읽어라.

## 목표
실행 가능한 명리 아틀리에 웹서비스를 완성한다. `web/index.html`은 디자인 프로토타입이고, `knowledge/`는 17개 연구용 Markdown, `docs/`는 PRD/설계/검증 명세다. 이를 Next.js TypeScript Tailwind + FastAPI Python으로 확장하라. 사용자 입력 → 만세력 검증 → 규칙·고전 검색 → 한국어 AI 설명 → 개인정보 가림 공유 흐름을 구현하라.

## 강제 조건
1. 원전/주석/현대 추론 구분. 출처와 rule_id가 없으면 고전 주장을 만들어내지 말 것.
2. 결정론적 만세력 계산을 LLM에 맡기지 말고 독립 라이브러리 + 절기 출처 + 교차검증 테스트로 구현. 천문 시각은 신뢰할 수 있는 역법 데이터 기반으로 구축. 검증 불가 시 UI에 '계산 검증 대기' 표시.
3. 서울 2000-01-01 19:25 남성 양력 사례를 검증할 것. 표준시/평균태양시/진태양시 3개 옵션, 한국 해당 연도 DST 종료, 야자시, 절기, 시주 차이를 테스트. 앞선 명식은 정답으로 하드코딩하지 말 것.
4. 이름 미입력, 출생시간 모름, 음력·윤달, 출생지 선택, 4인 가족 다중 입력 UI는 설계하되 개인정보는 저장하지 않는 것을 기본으로. 공유 시 가림/만료/취소.
5. UI는 ivory #F7F6F1, ink #242F30, teal #1F6760, gold #BE9864. 전문적인 모바일 반응형 UI; 첫 화면 요약, 명식 카드, 주요 해석 카테고리, 근거·학파 차이를 단계적으로.
6. 건강·사망·부동산·승진·재물의 확정 예측 금지, 의학/투자 조언과 명리 상징 해석 구분.
7. 비밀키는 서버 환경변수만. `.env.example` 제공, 보안·rate limit·로그 비식별화. 데이터가 없다면 시뮬레이션 성공으로 위장 금지.

## 작업 순서
A. repo/기존 HTML/Markdown 점검, 위험사항과 필요한 라이브러리 제안. 개발계획을 TASKS.md에 기록.
B. Next.js 프로젝트 생성, `web/index.html` 디자인을 React 컴포넌트로 이식, 폼 검증과 접근성 구현.
C. FastAPI 만세력 API/계산기 구현 및 독립 검증. 최소 100개 고정 테스트; timezone DST/절기/윤달/야자시 테스트 통과.
D. 규칙 엔진을 `knowledge/`와 연결. 고전 근거 검증 상태가 기록된 rule registry. 원전 검증되지 않은 규칙은 보류.
E. LLM을 JSON 구조화 출력으로 연결. 근거 없으면 '해석 유보'; API 키 없을 땐 근거가 검증된 설명만 출력.
F. 프라이버시/공유(동의/비식별/만료/삭제), PDF 및 다운로드, UX 마무리.
G. 단위·통합·e2e 테스트, README 실행 문서, Windows 실행 스크립트, 배포 방법 작성.

## 종료 조건
- `npm run dev`와 백엔드 동시 실행 가능.
- 예제 입력이 오작동 없이 명식을 산출하며 두 개 이상의 독립 검증 자료와 대조 결과가 TEST_REPORT.md에 남음.
- 검증되지 않은 계산은 정확한 척하지 않음.
- `/docs` API 설명 및 에러 처리.
- 반응형 360px/1440px 화면 QA.
- 실제 API 키 없이도 데모 UI 작동(단 계산 및 AI 결과를 사실로 위장 금지).
- 변경사항, 실행 방법, 남은 미검증 항목을 마지막에 한국어로 요약.

**중요:** 파일이 이미 있는 경우 확인 없이 덮어쓰지 말고, 개발 단계마다 실행/테스트하여 오류를 수정하라. 외부 패키지 설치 또는 API 사용이 막히면 가능한 범위까지 구현하고 미완료 항목은 명시하라.
